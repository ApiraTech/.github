# ApiraTech

ApiraTech builds software and automation. This organization profile collects our public
projects and the shared community standards used across our GitHub repositories.

## Contributing

Repository-specific documentation takes precedence. When a repository does not provide local
guidance, see our organization-wide
[contributing guide](https://github.com/ApiraTech/.github/blob/main/CONTRIBUTING.md) and
[code of conduct](https://github.com/ApiraTech/.github/blob/main/CODE_OF_CONDUCT.md).

## Security

Please do not report vulnerabilities in public issues. Follow our
[security policy](https://github.com/ApiraTech/.github/security/policy) to make a private report.
