# Support

For usage questions, first review the repository's README and documentation. If the repository
has GitHub Discussions enabled, use it for questions and general help. Otherwise, open an issue
with enough context for someone else to reproduce or understand the problem.

Please remember:

- maintainers may not be able to provide individual or time-sensitive support;
- keep bug reports focused and remove credentials, personal data, and other secrets; and
- report suspected vulnerabilities privately by following [SECURITY.md](SECURITY.md), never in
  an issue or discussion.
